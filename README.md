This project implements a Retrieval-Augmented Generation (RAG) application in Python using the Gemini API. The system processes the PDF version of The 100: A Ranking of the Most Influential Persons in History by Michael H. Hart, enabling the AI to answer questions and generate insights based on the book’s content. The application demonstrates key AI concepts such as document parsing, vector embeddings, retrieval-based context management, and LLM-powered response generation. By combining RAG techniques with the Gemini API, the system can provide accurate, context-aware answers from a large textual source.
